Looking inside

Tools for seeing what a model has learned.

Neuronpedia

Neuronpedia · tool

An open-source platform for interpretability, the study of what happens inside a model. Browse the features that sparse autoencoders find in real models, see the text that sets each one off, and steer a model with them.

  • On the Lineage
  • Towards Monosemanticity 2023

Embedding Atlas

Apple · tool

A tool for exploring large sets of embeddings, where each item is placed as a point so that similar items sit close together. Search, filter and zoom across the whole map in your browser.
